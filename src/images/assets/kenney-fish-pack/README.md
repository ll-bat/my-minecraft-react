# Kenney Fish Pack

This directory contains a curated copy of three fish illustrations from Kenney's **Fish Pack 2.0**, together with its original preview and license.

- Source: https://kenney.nl/assets/fish-pack
- Creator: Kenney
- License: Creative Commons Zero 1.0 (CC0)
- Downloaded: 2026-10-11

The original 128 × 128 blue, orange, and pink PNG files are packed into the game's item atlas. Their shapes and palettes are also used as the reference for the matching low-poly swimming models.
