# Kenney Voxel Pack

This directory contains a curated, implementation-ready copy of the PNG artwork from Kenney's **Voxel Pack**:

- `tiles/`: 85 terrain, building, plant, fluid, ore, and utility textures at 128 × 128 pixels.
- `items/`: 56 transparent item and tool illustrations.
- `preview.png`: the pack's original overview image.
- `LICENSE.txt`: the license file distributed with the archive.

Source: <https://kenney.nl/assets/voxel-pack>

Downloaded: 2026-10-10

License: Creative Commons Zero 1.0 (CC0). Attribution is not required, but credit to Kenney is appreciated.

These files are source assets and are not wired into the game yet. Before integration, choose whether the world will use their smooth 128 × 128 style directly or derive a smaller pixel-art atlas from them. Keep the originals in this directory so later processing remains reproducible.
