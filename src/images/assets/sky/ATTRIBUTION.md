# Sky asset sources

- `sun-nasa.png` is derived from NASA Solar Dynamics Observatory imagery published by NASA Scientific Visualization Studio: https://svs.gsfc.nasa.gov/4269/
- `moon-nasa.jpg` is the NASA Scientific Visualization Studio CGI Moon Kit color texture adjusted to resemble human vision: https://svs.gsfc.nasa.gov/4720/
- `stars-nasa.jpg` is derived from NASA Scientific Visualization Studio's Deep Star Maps 2020: https://svs.gsfc.nasa.gov/4851/
- `cloud-layer-polyhaven.png` is derived from **Cloud Layers** by Greg Zaal on Poly Haven: https://polyhaven.com/a/cloud_layers

NASA Scientific Visualization Studio material is public domain unless an asset says otherwise. The Poly Haven source is licensed CC0.
